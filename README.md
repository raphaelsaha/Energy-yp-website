# Energy Young Professionals website

A lightweight, responsive, single-page website for Energy Young Professionals (Amsterdam).

## Preview locally

Download `index.html` and double-click it to open it in a browser. No installation or build tools are required.

## Upload to GitHub

1. Create a new repository (for example, `energy-yp-website`).
2. Choose **Add file → Upload files**.
3. Upload `index.html` and `README.md` from this folder, then commit.

## Publish with Cloudflare Pages

1. In Cloudflare, go to **Workers & Pages** and create a Pages project.
2. Connect your GitHub repository and choose this repository.
3. Use the static HTML preset / no framework. Leave build command blank and use the repository root (`/`) as the output directory.
4. Deploy. Check the `*.pages.dev` preview URL.
5. In the Pages project, add `energyyoungprofessionals.org` under **Custom domains** and follow Cloudflare's DNS instructions. Set up `www` as an additional domain if desired.

## Before public launch

- Confirm the next event details (26 November 2026 is currently a save-the-date).
- Replace photo placeholders with real photos you have permission to publish.
- Confirm membership conditions and Meetup registration flow.
- Configure and add a contact email or form.
- Review text, accessibility, mobile layout, and all links.

## How to edit

Open `index.html` in GitHub and select the pencil (Edit) icon. Commit changes to trigger automatic Cloudflare deployment once the integration is configured.
